### Cách chụp screenshot với DevTools:

1. Mở `responsive.html` trong Chrome/Firefox
2. Nhấn `F12` để mở DevTools
3. Click icon **Toggle Device Toolbar** (Ctrl+Shift+M)
4. Chọn kích thước:
   - iPhone SE → 375×667
   - iPad → 768×1024
   - Desktop → 1440×900
5. Chụp màn hình từng size
